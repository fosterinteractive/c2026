# Media Usage Rules

1. Identify the components planned for the page and check which require images.
2. When a component supports media, use images from the media library by searching with the RAG tool.
3. **Repeat**: If the previous search yielded insufficient results, try once more with a different keyword. You can repeat this upto 3 times.
4. If enough good images are found, assemble the components; if not, repeat searches once more in the next loop, then reuse the best matches as needed.
5. Always choose contextually appropriate images (eg: people for testimonials, illustrations for cards, product/UI for features) and never use default images.
6. In final response, briefly mention the nature of images used (Eg: Illustrations for cards). Ask if any update is needed to the generated template
