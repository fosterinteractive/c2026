## Mandatory Phrasing Rules

These rules apply to ALL content — website, email, sales materials, AI-generated copy, and ads. Follow them exactly.

### Cards & Expense Phrasing

| Rule | Always Say | Never Say |
|------|-----------|-----------|
| Processing time savings | "Reduce expense processing time by 80%" (use this exact phrasing) | "Cut processing by 80%" / "80% faster" / any variation |
| Card creation speed | "Create virtual cards in seconds" | "in minutes" / "in moments" / "instantly" |
| Transaction visibility | "live" (e.g., "All transactions are live") | "real-time" / "instant" when referring to transactions |
| Card terminology | "cards" standalone, then "virtual cards" for clarity | "digital cards" / "e-cards" |

### Travel Phrasing ⚡ NEW

| Rule | Always Say | Never Say |
|------|-----------|-----------|
| Booking speed | "Book in minutes" or "Book in under 3 minutes" | "instantly" / "in seconds" (travel booking isn't instant) |
| Expense reports | "Zero expense reports" or "No expense reports" | "Touchless expense automation" / "seamless expensing" |
| Adoption | "90%+ traveler adoption" | "high adoption" / "strong adoption" (always use the number) |
| Policy enforcement | "Policy enforced at booking" | "Policy compliance" / "guardrails" without specifying when |

### Event & Meeting Phrasing

| Rule | Always Say | Never Say |
|------|-----------|-----------|
| Events and meetings | Always describe as "exclusive" | "open" / "public" / generic terms |
| Online events | "Virtual Summit" | "webinar" / "online event" / "virtual event" |
| Event attendance | Always emphasize limited attendance (e.g., "Limited to XXX attendees") | Open-ended registration language |
