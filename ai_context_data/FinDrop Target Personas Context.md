### Primary Personas (Confirmation Required)

For tasks to generate a complete page, before executing any sub agents:

1. List the available personas (Only name).
2. Ask the user to choose the target persona.
3. **Do not generate the page until confirmed.**
4. Pass the selected persona as context to the sub-agent.
5. If none is chosen, prompt again.

**Personas**

* **Controllers & Finance Managers** - need spend visibility; struggle with manual tracking.
* **Staff Accountants & AP Teams** - need to remove manual processing; face reconciliation bottlenecks.
* **Project Managers** - need real-time expense tracking; risk budget overruns.
* **IT & Ops Teams** - need subscription/vendor control; face unauthorized spend.
