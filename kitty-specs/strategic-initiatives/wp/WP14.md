## Description

Service that bridges Drupal Tool API plugins to the MCP tool format. Iterates `ToolManager::getDefinitions()`, filters for `ai_agents_canvas_direct_edit:*` tools, and converts their input definitions to JSON Schema.

### Implementation Notes

- Place in `src/Service/McpToolBridge.php`
- Inject `ToolManager` (plugin manager for Tool API)
- `listTools(): array` — maps each Tool plugin to `{name: string, description: string, inputSchema: object}`
- `executeTool(string $name, array $arguments, AccountInterface $account): array` — loads plugin, checks `checkAccess()`, executes, returns result
- Filter tools by module prefix to only expose canvas direct-edit tools
- Input schema conversion: Tool API `InputDefinition` → JSON Schema object

### Test Cases

- `listTools()` returns all 8 tools
- Each tool has valid JSON Schema input definition
- `executeTool()` on read tool returns expected result
- `executeTool()` on write tool without permission returns access denied
- Unknown tool name returns error
