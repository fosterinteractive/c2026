## Description

Create an immutable `TelemetryEvent` value object that carries all telemetry fields. Uses builder pattern for ergonomic construction from controller code.

### Implementation Notes

- Place in `src/Telemetry/TelemetryEvent.php`
- PHP 8.3 readonly properties, `declare(strict_types=1)`
- Builder: `TelemetryEvent::create()->withComponentName('heading')->withTier('exact')->...->build()`
- Nullable fields for confidence, complexity_signal, model_used (populated by later initiatives)
- `messageHash` computed automatically from raw message in builder

### Test Cases

- Builder produces correct immutable object
- Hash computed correctly from message
- Nullable fields default to null
- Object is truly immutable (readonly properties)
