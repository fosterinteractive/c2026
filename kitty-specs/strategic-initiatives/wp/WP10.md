## Description

Modify `DirectEditMatcher::match()` and `matchSingle()` to return `MatchResult` objects with confidence scores. Each tier assigns a confidence based on match quality.

### Implementation Notes

- Tier 1 (exact prop name): confidence 1.0
- Tier 2 (semantic alias): confidence 0.95
- Tier 3 (enum value): confidence 0.90
- Tier 4 (relative adjustment): confidence 0.85
- Tier 5 (bare value/reset): confidence 0.80
- No match: confidence based on nearest-miss analysis:
  - Had a prop name match but no value: 0.6
  - Had an edit verb but no prop: 0.4
  - No recognizable pattern: 0.1
- Compound edits: confidence = min(fragment confidences)

### Test Cases

- Exact match returns confidence 1.0
- Alias match returns confidence 0.95
- No-match with verb detected returns ~0.4
- No-match with no recognizable pattern returns ~0.1
- Compound edit confidence is min of fragments
- All 52 existing tests pass (ArrayAccess compat handles return type change)
