## Description

Create a service that checks whether any AI provider is configured and usable for chat operations. This is the foundation for API-key-free mode.

### Implementation Notes

- Place in `src/Service/AiProviderAvailabilityChecker.php`
- Inject `AiProviderPluginManager` (service: `ai.provider`)
- `isAiAvailable(): bool` — calls `getDefaultProviderForOperationType('chat')`, returns false if null or if `isUsable()` returns false
- No caching — config changes take effect immediately
- Register in `*.services.yml`

### Test Cases

- Returns true when a chat provider is configured and usable
- Returns false when no default provider set
- Returns false when provider exists but is not usable (e.g., missing API key)
